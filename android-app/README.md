# تطبيق مكتبة النصر لنظام Android

تطبيق Android خفيف يعرض موقع مكتبة النصر الحي داخل نافذة آمنة. يبقى محتوى التطبيق مواكباً للموقع المنشور، لذلك يلزم اتصال بالإنترنت لعرض المنتجات. روابط الهاتف وواتساب تُفتح في التطبيقات المناسبة على الجهاز.

## البناء

يتطلب المشروع Java 17 أو أحدث وAndroid SDK مع Android API 35 وGradle 8.9. من هذا المجلد شغّل:

```sh
./gradlew assembleDebug
```

ينتج APK قابل للتثبيت وموقّع بمفتاح Android debug الافتراضي في:

```text
app/build/outputs/apk/debug/app-debug.apk
```

كما يبني GitHub Actions الملف ويرفعه كأثر تنزيل باسم `nasr-library-android-apk` عند تحديث مجلد `android-app` أو تشغيل سير العمل يدوياً.

## معلومات التطبيق

- الاسم: مكتبة النصر
- معرّف الحزمة: `com.yusufelbeses.nasrlibrary`
- الإصدار: `1.3.0`
- الموقع: `https://albshshy-alt.github.io/alnasrshopap4/`
- أقل إصدار Android مدعوم: Android 6.0 (API 23)
- الفاتورة PDF عادت إلى تنسيق إيصال الكاشير البسيط: رأس أخضر، تفاصيل الفاتورة، وجدول المنتجات والإجمالي، مع حقوق مكتبة النصر.
- عند المشاركة يحاول التطبيق فتح واتساب مباشرة على رقم مكتبة النصر `+963 954 672 747` مع إرفاق PDF. إذا لم يقبل إصدار واتساب التوجيه المباشر، تظهر قائمة المشاركة للاختيار يدوياً. يجب تأكيد الإرسال داخل واتساب.
- من زر الإعدادات يمكن عرض آخر 50 عملية/فاتورة، واختيار العربية أو الإنجليزية، والاطلاع على إشعار الملكية ووسيلة خدمة العملاء. سجل العمليات محفوظ محلياً على الجهاز ولا تتم مزامنته.
- تتغير لغة عناصر الواجهة والفاتورة؛ تبقى أسماء المنتجات كما هي في قائمة الأسعار العربية.
- في متصفح الهاتف أو الكمبيوتر، اختر زر الفاتورة ثم «حفظ كـPDF» من نافذة الطباعة.
